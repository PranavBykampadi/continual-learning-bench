# PR #226: money: add scale() and comparisons to Money (PRC-067)
Merged: 2025-11-18

**Priya** opened this pull request.

Follow up to the rounding incident in October. `Money` was missing a couple of things people need before they can actually use it:

- `scale(factor)` for percentages, rounds half up to the cent
- `<` and `<=`
- docstring on `parse`

No callers change in this PR.

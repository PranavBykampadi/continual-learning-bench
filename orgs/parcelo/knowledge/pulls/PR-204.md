# PR #204: ci: pin pip and install from the package mirror (PRC-047)
Merged: 2025-09-08

**Kenji** opened this pull request.

pip on the CI runners keeps hanging while resolving dependencies (third time this month). This pins pip to a known good version and points the install step at the internal package mirror instead of the public index.

- pin pip in the CI image setup
- `--index-url` set to the mirror
- 10 min timeout on the install step so a hang fails fast instead of eating the whole job

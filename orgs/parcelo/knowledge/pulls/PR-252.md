# PR #252: shipments: validate zone and weight on create (PRC-088)
Merged: 2026-02-12

**Lena** opened this pull request.

Creating a shipment with an unknown zone or a weight of 0 used to go through and blow up later when we tried to price it. This checks both up front in `create_shipment`.

---

**Priya** commented:

on the zone check:

```python
raise ValueError("unknown zone: %s" % zone)
```

new code shouldn't raise `ValueError` (or `KeyError`) for stuff like this. raise `DomainError` from `parcelo.errors` with a code that's registered in `errors.CODES`. the API layer maps those codes to proper 4xx responses with a code support can look up. a `ValueError` falls through to a generic 500, and then Rosa gets a screenshot that says "internal error" and has to escalate to us

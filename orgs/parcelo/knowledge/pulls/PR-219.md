# PR #219: ci: cache the venv between runs (PRC-061)
Merged: 2025-11-07

**Tomasz** opened this pull request.

CI median is ~11 min and about 6 of that is installing the same packages on every run. This caches the venv keyed on the hash of the requirements files.

Before: 10m50s median over the last 50 runs
After: 4m55s median over 20 runs on this branch
